# ขอบเขตโครงงาน

## ชื่อโครงงาน

การพัฒนาระบบปัญญาประดิษฐ์และระบบสนับสนุนการตัดสินใจสำหรับการบริหารการปล่อยเช่าคอนโดมิเนียมในรูปแบบเว็บแอปพลิเคชัน

## เป้าหมาย

1. เพื่อพัฒนาโมเดลแนะนำราคาค่าเช่าที่เหมาะสม (Rental Price Recommendation) โดยพิจารณาจากปัจจัยแวดล้อมและสภาวะตลาด
2. เพื่อพัฒนาโมเดลพยากรณ์สภาวะตลาดและอัตราการเข้าพักล่วงหน้า (Market & Occupancy Forecasting)
3. เพื่อพัฒนาระบบ What-if Simulation สำหรับจำลองสถานการณ์การปรับราคาและประเมินผลกระทบต่อรายได้
4. เพื่อพัฒนาระบบสนับสนุนการตัดสินใจด้วย AI ผ่าน Web Application

งานของอาทิตยาใน Repository นี้เน้นวัตถุประสงค์ข้อ 1 และการเชื่อมต่อผลโมเดลกับวัตถุประสงค์ข้อ 3-4 ส่วนการพัฒนาโมเดล Market & Occupancy Forecasting ตามวัตถุประสงค์ข้อ 2 เป็นความรับผิดชอบของเพื่อนร่วมโครงงาน

## กติกาหลัก

1. ใช้ข้อมูลใน `data/raw/` เป็นข้อมูลต้นฉบับแบบอ่านอย่างเดียว
2. เก็บผลการทำความสะอาดไว้ใน `data/processed/`
3. สร้าง Modeling Dataset ใหม่ทุกครั้งด้วยโค้ด ไม่แก้ CSV ด้วยมือ
4. แบ่ง Train, Validation และ Test ตามเวลาเดียวกันทุกโมเดล
5. เลือกโมเดลจาก Validation และใช้ Test เพียงครั้งเดียวหลังล็อกโมเดล
6. ตรวจสอบ Data Leakage โดยถามว่าตัวแปรนั้นทราบแล้วหรือยังก่อนเวลาทำนาย
7. โปรโมชั่นรุ่นแรกจำกัดเฉพาะสิ่งที่แปลงเป็นผลกระทบด้านราคาได้
8. ตัวเลขรายได้จากระบบเรียกว่า “รายได้ประมาณการ” ไม่ใช่กำไรจริง

## โปรโมชั่นในรุ่นแรก

- ส่วนลดค่าเช่าเป็นเปอร์เซ็นต์
- ส่วนลดค่าเช่าเป็นจำนวนเงิน
- ฟรีค่าเช่าบางเดือน
- ส่วนลดช่วงแรกของสัญญา
- ส่วนลดเมื่อต่อสัญญา
- คงราคาเดิมเมื่อต่อสัญญา

โปรโมชั่นที่เป็นของแถม บริการ หรือสิทธิประโยชน์ที่ไม่มีข้อมูลต้นทุนจะยังไม่ใช้เป็น Feature ฝึกโมเดล
