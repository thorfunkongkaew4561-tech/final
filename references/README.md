# เอกสารอ้างอิง

## `papers/rental_price/`

เก็บเฉพาะเปเปอร์ที่ใช้สนับสนุนวัตถุประสงค์ข้อ 1 และการเลือกโมเดล
พยากรณ์ราคาเช่าในโครงงานนี้

| แนวทางหรือโมเดล | เปเปอร์ที่ใช้อ้างอิง |
|---|---|
| Stepwise Multiple Linear Regression | แบบจำลองพยากรณ์อัตราค่าเช่าที่อยู่อาศัยรอบมหาวิทยาลัยธรรมศาสตร์ ศูนย์รังสิต |
| Gradient Boosting | Prediction of residential real estate price on primary market using machine learning |
| Random Forest | Rental Price Prediction of Boarding Houses in Batam City Using Linear Regression and Random Forest Algorithms |
| KNN | A Machine Learning Approach Using Spatially Explicit K-Nearest Neighbors for House Price Predictions |
| ANN | Appropriate Rental Price Prediction for Condominiums in Pattaya, Thailand Using Artificial Neural Network Approach |

## `templates/`

เก็บแบบฟอร์มหรือเอกสารตัวอย่างที่ใช้ดูโครงสร้างและรูปแบบของรายงาน
ไม่ใช้เป็นแหล่งอ้างอิงผลการทดลองของโมเดล
